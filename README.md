## Project Overview

TrustVault is a secure document-sharing application built with Python and Flask. It is designed to manage documents, control access, and maintain an audit trail of important activities.

## Features

- User authentication and role-based access control
- Document upload and management
- Document-level permissions
- Secure file validation and storage
- Activity audit logging
- Automated tests

## Technology Stack

- Python
- Flask
- SQLite
- HTML, CSS, JavaScript
- Pytest

## Setup Instructions

1. Install Python.
2. Create and activate a virtual environment.
3. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Initialize the database using the project's documented setup process.
5. Start the application using the verified run command.

## Running Tests

Activate the virtual environment and run:

```bash
python -m pytest -v
```

The project test suite passed 60 tests in the local development environment.

## Security

TrustVault includes document-access controls, file validation, and audit-logging functionality. Review the implementation and test results before using it with sensitive documents.
